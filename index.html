Demo on a test site

WordPress "critical error" after a PHP update

SymptomThe whole site showed "There has been a critical error on this website."
CauseThe error log pointed to an old plugin calling create_function(), which PHP 8 removed.
FixRewrote that line as a modern function, with no data lost and no plugin removed.
ProofHome page and specials list load again. Log is clean.
Demo on a test site

Contact form says "Thanks!" but no email arrives

SymptomVisitors saw "Thanks! We got your message", but the owner never got it.
CauseThe log showed wp_mail_failed: Invalid address: (From): wordpress@localhost. The form ignored the failure.
FixSender on the site's own domain, authenticated SMTP, and an honest error if sending fails.
ProofThe test message arrived with the visitor as Reply-To.
Demo on a test site

Order buttons cut off on phones

SymptomOn a phone only one and a half boxes showed. The third "Order now" button was off screen.
CauseThe box row had a fixed width of 900px, wider than any phone.
FixLet the boxes wrap so they fit any screen size.
ProofAll three boxes and buttons show on a 390px wide phone.
